# 后端开发任务：视频搞笑检测系统 - 核心模块实现

## 1. 任务描述

根据系统设计方案文档，逐步实现视频搞笑检测系统的核心后端模块，包括：

- 项目结构和配置模块
- B站爬虫模块
- 视频处理模块
- AI 搞笑评分模块
- FastAPI 接口层
- 数据库模型

## 2. 代码实现

### 2.1 项目结构

```
e:\t\five\
├── config/
│   └── config.yaml          # 配置文件
├── src/
│   ├── core/
│   │   └── config.py        # 配置加载模块
│   ├── models/
│   │   └── database.py      # 数据库模型
│   ├── services/
│   │   ├── bilibili.py     # B站爬虫
│   │   ├── video.py         # 视频处理
│   │   └── ai_analyzer.py  # AI 搞笑评分
│   └── api/
│       └── routes/
│           ├── health.py    # 健康检查
│           └── video.py     # 视频 API
├── main.py                  # 应用入口
├── requirements.txt         # 依赖清单
└── test_install.py          # 安装检查脚本
```

### 2.2 核心功能模块

| 模块 | 文件 | 功能 |
|------|------|------|
| 配置管理 | `src/core/config.py` | 加载 YAML 配置，提供类型安全的配置访问 |
| B站爬虫 | `src/services/bilibili.py` | 视频信息获取、弹幕/评论抓取 |
| 视频处理 | `src/services/video.py` | FFmpeg 封装、帧提取、音频提取 |
| AI分析 | `src/services/ai_analyzer.py` | Deep Seek API 搞笑评分 |
| 数据库 | `src/models/database.py` | SQLAlchemy ORM 模型定义 |
| API | `src/api/routes/video.py` | FastAPI RESTful 接口 |

## 3. 自检报告

### 3.1 Bug 检查

- [ ] **逻辑错误**: 无重大逻辑错误
  - B站爬虫 URL 解析使用正则匹配，支持 BV/AV/EP/SS 多种格式
  - AI 评分模块对 API 返回值做了容错处理
- [ ] **边界条件处理**: 已处理
  - 空评论/弹幕列表时使用默认值
  - API 调用失败时返回 50.0 默认分
- [ ] **异常处理**: 完整
  - 所有外部调用（HTTP、FFmpeg、API）都有 try-catch
  - 自定义异常类：`BilibiliParseError`、`VideoProcessError`、`AIAnalysisError`
- [ ] **资源泄漏**: 已处理
  - `BilibiliCrawler` 提供 `close()` 方法
  - 数据库会话使用依赖注入自动关闭

### 3.2 代码不合理检查

- [ ] **重复代码**: 无明显重复
  - 配置使用单例模式 + LRU 缓存
  - 爬虫、视频处理器通过工厂函数获取实例
- [ ] **命名规范**: 符合 PEP8
  - 类名使用 CamelCase
  - 函数名使用 snake_case
  - 常量使用 UPPER_SNAKE_CASE
- [ ] **性能问题**: 无明显性能问题
  - 数据库使用索引优化查询
  - FFmpeg 调用为同步阻塞，但适合当前规模
- [ ] **安全隐患**: 已检查
  - ✅ 无 SQL 注入（使用 SQLAlchemy ORM 参数化查询）
  - ✅ 无密码明文（无用户认证模块）
  - ✅ API Key 存储在配置文件中，不硬编码
  - ⚠️ 建议：生产环境应使用环境变量存储敏感信息
