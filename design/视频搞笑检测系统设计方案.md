# 视频搞笑检测系统 - 轻量级设计方案

## 1. 背景与目标

**目标**：构建一个支持多平台的视频抓取与搞笑程度分析系统，用于自动评估视频的搞笑程度，并收集评论、文字等数据，最终形成可对外提供的工具产品。

**核心价值**：帮助用户快速筛选高质量搞笑视频，降低人工筛选成本。

---

## 2. 核心功能

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 视频下载 | 支持B站、抖音、快手等主流平台 |
| P0 | AI搞笑评分 | 核心功能，通过视觉+音频+文案多维度分析 |
| P0 | 评论抓取 | 获取视频下热门评论数据 |
| P1 | 文字提取 | 提取字幕、弹幕、标题等文字信息 |
| P1 | 视频管理 | 视频列表、搜索、筛选、排序 |
| P2 | 数据导出 | 支持导出Excel/CSV |
| P2 | 定时任务 | 自动定时抓取更新 |

                            │
                            ▼

| 层级 | 技术选型 | 理由 |

## 5. 核心流程

### 5.1 视频抓取流程

```
用户输入视频URL
       │
       ▼
  验证URL平台类型
       │
       ├─── B站 ───→ 调用B站API/解析弹幕 ──→ 下载视频 ──→ 提取字幕
       │
       ├─── 抖音 ───→ 调用抖音API ──→ 下载无水印视频 ──→ 提取字幕
       │
       └─── 快手 ───→ 类似处理
```

### 5.2 AI搞笑检测流程（核心）

```
视频文件
    │
    ▼
┌─────────────────────────────────────────────────────────┐
│                    多模态分析                            │
│  ┌───────────┐  ┌───────────┐  ┌───────────┐         │
│  │ 视觉分析   │  │ 音频分析   │  │ 文案分析   │         │
│  │ (关键帧)   │  │ (笑声检测) │  │ (NLP模型)  │         │
│  └─────┬─────┘  └─────┬─────┘  └─────┬─────┘         │
│        └──────────────┼──────────────┘                │
│                       ▼                                │
│              综合评分引擎                              │
│              (0-100分)                                 │
└─────────────────────────────────────────────────────────┘
```

**评分维度说明**：
- **视觉**：人物表情夸张度、动作幅度、场景意外性
- **音频**：笑声检测、语气语调、音频特效
- **文案**：标题/字幕的幽默度、反转程度

### 6.2 索引设计

```sql
-- 视频表索引
CREATE INDEX idx_videos_platform ON videos(platform);
CREATE INDEX idx_videos_status ON videos(status);
CREATE INDEX idx_videos_created ON videos(created_at);

-- 评分表索引
CREATE INDEX idx_evaluations_video ON evaluations(video_id);
CREATE INDEX idx_evaluations_score ON evaluations(humor_score);

-- 评论表索引
CREATE INDEX idx_comments_video ON comments(video_id);
```

## 7. 模块职责

| 模块 | 职责 | 输入 | 输出 |
|------|------|------|------|
| **爬虫调度器** | 统一管理各平台爬虫，任务队列 | 视频URL | 下载的视频文件 |
| **B站爬虫** | B站视频/弹幕/评论获取 | BID | 视频+字幕+评论 |
| **抖音爬虫** | 抖音视频/评论获取 | 分享链接 | 视频+评论 |
| **视频处理器** | 提取关键帧、音频 | 视频文件 | 帧序列、音频文件 |
| **搞笑检测模型** | 多模态搞笑评分 | 视频+字幕 | 评分结果 |
| **数据服务** | 增删改查操作 | API请求 | JSON响应 |

## 8. 部署方案

### 8.1 开发环境

```bash
# Docker Compose 一键启动
services:
  api:
    build: ./api
    ports: 8000:8000
  worker:
    build: ./worker
    volumes: ./data:/app/data
```

### 8.2 生产环境

- **服务器**：2核4G云服务器（初期足够）
- **存储**：视频文件建议使用对象存储（OSS/COS），节省磁盘
- **备份**：数据库每日自动备份

## 9. 风险与注意事项

| 风险 | 应对措施 |
|------|----------|
| 平台反爬限制 | 控制请求频率，使用代理IP池 |
| AI模型效果 | 初期用规则+轻量模型，后续迭代优化 |
| 存储成本 | 视频压缩或使用对象存储 |
| 版权问题 | 仅供个人学习使用，明确免责声明 |
| API限流 | 添加请求间隔，合理使用配额 |
